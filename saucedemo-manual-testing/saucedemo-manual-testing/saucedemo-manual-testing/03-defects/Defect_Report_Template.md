# Defect Report Template (copy into each JIRA ticket)

**Issue type:** Bug   **Project:** SD

**Summary:** [Module] Short, specific description (e.g. `[Inventory] Sort does nothing for problem_user`)

**Severity:** Critical / Major / Minor / Trivial
**Priority:** High / Medium / Low
**Labels:** `saucedemo`, `<module>`

**Environment:** Chrome <version>, <OS>, https://www.saucedemo.com, user: <username>
**Linked test case:** TCxx
**Requirement:** REQ-xx

**Preconditions:**
- Logged in as <user>

**Steps to reproduce:**
1. ...
2. ...
3. ...

**Expected result:** ...

**Actual result:** ...

**Reproducibility:** Always / Sometimes (x of y attempts)

**Attachments:** annotated screenshot `SD-<n>.png` (red box/arrow on the problem) or short screen recording

---
## Writing tips
- One defect per ticket. Do not combine two bugs.
- Steps must be reproducible by a stranger.
- Expected result must come from a requirement, not opinion.
- Rename screenshots to match ticket IDs: `screenshots/SD-1.png`.
